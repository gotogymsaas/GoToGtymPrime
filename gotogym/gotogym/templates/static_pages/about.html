{# ---------- Ciencia de materiales: grafeno ---------- #}

{% trans "Ciencia de materiales" %}

{% blocktrans trimmed %}Grafeno: un átomo de espesor, propiedades fuera de escala.{% endblocktrans %}

{% blocktrans trimmed %}En 2004 se aisló por primera vez una capa de carbono de un solo átomo de grosor[1]. Seis años después, el hallazgo recibió el Premio Nobel de Física[2]. Hoy se investiga cómo llevar esas propiedades a la ropa deportiva. Esto es lo que está demostrado, con su fuente.{% endblocktrans %}

  • {% trans "1 átomo" %} {% blocktrans trimmed %}de espesor: una sola capa de carbono[3]{% endblocktrans %}
  • {% blocktrans trimmed %}≈ 5.000 W/m·K{% endblocktrans %} {% blocktrans trimmed %}conductividad térmica, más de 10 veces la del cobre[6][7]{% endblocktrans %}
  • 130 GPa {% blocktrans trimmed %}resistencia intrínseca medida en una monocapa[5]{% endblocktrans %}
  • {% blocktrans trimmed %}2,3 %{% endblocktrans %} {% blocktrans trimmed %}de la luz que absorbe una sola capa[8]{% endblocktrans %}

{% trans "Valores medidos en una monocapa casi ideal, en condiciones de laboratorio. Describen el material, no una prenda." %}

{% trans "Qué es, con precisión" %}

{% trans "De grafito a grafeno: es cuestión de capas." %}

{% blocktrans trimmed %}La norma ISO/TS 80004-13 define el grafeno como una sola capa de átomos de carbono[3]. Entre tres y diez capas se llama grafeno de pocas capas[4]; con muchas, es grafito. En los textiles es habitual usar derivados como el óxido de grafeno, que no se comportan igual que la lámina ideal[16]. Saber qué forma lleva una prenda es la primera pregunta útil.{% endblocktrans %}

{% trans "Calor" %}

{% trans "Un conductor térmico fuera de lo común." %}

{% blocktrans trimmed %}En una monocapa suspendida se midió una conductividad térmica de entre 4.840 y 5.300 W/m·K a temperatura ambiente[6]. El cobre, referencia de los buenos conductores, ronda los 401 W/m·K[7]. De esa propiedad nace el interés por prendas que repartan mejor el calor del cuerpo[9].{% endblocktrans %}

{% trans "De la lámina a la prenda" %}

{% trans "Tres maneras de llevar grafeno a un textil." %}

01

{% trans "Recubrimiento" %}

{% blocktrans trimmed %}La tela se trata con grafeno o con óxido de grafeno reducido. Es la vía de los calefactores textiles y de varios sensores[10][14].{% endblocktrans %}

02

{% trans "Fibra compuesta" %}

{% blocktrans trimmed %}El grafeno se integra al polímero antes de hilar. Es el caso de las prendas de compresión del ensayo en humanos[11].{% endblocktrans %}

03

{% trans "Película laminada" %}

{% blocktrans trimmed %}Una película de grafeno se encapsula junto a un tejido, como en sensores de deformación sobre nailon[13].{% endblocktrans %}

{% trans "En los tres casos, el resultado depende de cuánto material hay, de su forma y de que siga adherido tras el uso y el lavado." %}

{% trans "Beneficios posibles" %}

{% trans "Qué puede aportar, y con qué evidencia." %}

{% trans "Gestión térmica" %}

{% blocktrans trimmed %}Reparte el calor y, con una pequeña fuente de energía, puede generarlo en prendas con calefacción[9][10].{% endblocktrans %}

{% trans "Prototipos y revisiones" %}

{% trans "Sensado del movimiento" %}

{% blocktrans trimmed %}Sensores finos y flexibles integrados en la tela para seguir el movimiento del cuerpo[12][13][14].{% endblocktrans %}

{% trans "Mayormente prototipos" %}

{% trans "Rendimiento aeróbico" %}

{% blocktrans trimmed %}En un ensayo cruzado de doble ciego con 15 personas, el esfuerzo duró 38,4 s más (cerca de un 5 %) con prendas de grafeno. El VO₂máx no cambió[11].{% endblocktrans %}

{% trans "Un estudio pequeño, sin replicar" %}

{% trans "Actividad antibacteriana" %}

{% blocktrans trimmed %}El grafeno y el óxido de grafeno dañaron bacterias en el laboratorio[15]. En una prenda depende de la forma, del método de medición y del lavado[17].{% endblocktrans %}

{% trans "Ensayos de laboratorio" %}

{% trans "Resistencia mecánica" %}

{% blocktrans trimmed %}Módulo de Young de 1,0 TPa en una monocapa[5]. En una tela, lo que importa es cómo se integra a la fibra.{% endblocktrans %}
